# 🩸 Blood Donation Management System

A full-stack Blood Donation Management System developed using **Flask**, **MySQL**, **HTML/CSS/JavaScript (or Next.js frontend)**. The application allows users to register, log in, update their donor information, search for blood donors based on blood group, view donor details, and delete their profiles.

---

## 📌 Features

- User Registration
- User Login
- Update Donor Profile
- Search Donors by Blood Group
- View Donor Details
- Delete Donor Profile
- MySQL Database Integration
- REST API using Flask
- Responsive User Interface
